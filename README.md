# Personal Resume Website

Personal portfolio and resume website built using React and Vite.

## Technologies

- React
- JavaScript
- HTML
- CSS
- Vite

## Overview

This project showcases my professional experience, technical skills, education, and software development projects.

## Running Locally

Install dependencies:

    npm install

Start the development server:

    npm run dev

Build for production:

    npm run build
